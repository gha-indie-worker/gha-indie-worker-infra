## Parity boundary

The current Rust clone/worker lane is a bounded, security-focused fallback: exact
commit-SHA selection, signed webhook verification, repository/event allow-lists,
deterministic dependency ordering, fixed execution profiles, bounded workflow YAML,
retry/deduplication, and append-only run evidence. It is not yet a drop-in replacement
for the GitHub Actions control plane. The remaining parity surface includes expressions
and matrices, reusable workflows, environments/approvals, artifacts and caches,
check-runs/annotations, service containers, marketplace action execution, secret/OIDC
semantics, and hosted Windows/macOS runner behavior. Native GitHub Actions parity should
continue to use ARC on the cluster; this fallback must remain fail-closed when a
capability is not implemented.

The same capability axes are the useful comparison baseline for GitLab CI, Jenkins,
CircleCI, Azure Pipelines, Buildkite, Harness, Argo Workflows, Tekton, and Bitbucket
Pipelines. A product claim of “top-ten parity” is not made until each axis has an
executable conformance test and a hosted canary result.

## Activation checklist

1. Enable billing and the required GCP APIs; build immutable images, publish their
   digests, and apply the Cloud Run plan with the reviewed service accounts.
2. Configure Cloudflare DNS and the edge Worker from the checked-in generated
   `wrangler.toml`; enable Access and create admin applications with no fallback route.
3. Replace the intentional Cloud Run placeholder origins in `router.config.json` only
   with read-back service URLs from the applied deployment, then run the outside-in
   DNS/TLS/health checks.
4. Reconcile Neon private networking and Supabase project readiness, then run the
   database isolation tests against fresh provider evidence.
5. Deploy the webhook receiver, create one test-org canary repository, install a hook,
   and prove delivery → verification → bounded execution → status callback with the
   exact commit SHA. Expand repository coverage only after that canary is green.
